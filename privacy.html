Privacy Policy

Builder Plaza — Last updated: 14 July 2026

Builder Plaza is a cross-platform mobile application developed as an academic group project for the Mobile App Engineering module (CT124-3-2-MAE) at Asia Pacific University of Technology & Innovation, Technology Park Malaysia. This policy explains what data the application collects and how it is used.

1. Data we collect

When you sign in, Builder Plaza requests the following through official third-party authentication flows:

  • GitHub (OAuth): your public profile, public repository metadata (repository names, languages, topics, commit and pull-request activity). We do not access private repositories.
  • LinkedIn (Sign In with LinkedIn using OpenID Connect): your name, profile photo, and email address as provided by the OpenID Connect id token. We do not access your connections, messages, or activity feed.

Within the application you may additionally create profile information, project cards, availability status, collaboration requests, and messages.

2. How we use data

Data is used solely to operate the application's features: verifying account identity, displaying credibility signals derived from public code activity, generating collaboration match suggestions, and enabling in-app collaboration requests. Data is not sold, shared with advertisers, or used for any purpose outside this academic project.

3. Data retention and caching

LinkedIn member data is rendered on the fly at sign-in and is not persisted as a profile database; any cached LinkedIn data is retained for no longer than 48 hours, in line with LinkedIn API terms. Derived, de-identified skill embeddings may be stored to power matching. GitHub public activity data may be periodically refreshed to keep credibility signals current.

4. Data storage and security

Application data is stored on Amazon Web Services (AWS) infrastructure. All communication between the mobile client and the backend uses HTTPS. Uploaded images (profile photos, project screenshots) are stored in private object storage and served through time-limited pre-signed URLs.

5. Your choices

You may deactivate your account at any time from within the application, which removes your profile from discovery and matching. You may revoke Builder Plaza's access at any time from your GitHub and LinkedIn account settings.

6. Academic context

Builder Plaza is a student project and is not a commercial service. Test data used in demonstrations is either synthetic or anonymised.
